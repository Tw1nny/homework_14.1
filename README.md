# Проект: Категории и Продукты

## Описание
В этом проекте реализованы классы `Product` и `Category` для управления продуктами и категориями.

### Функционал:
- Класс `Product` с атрибутами: название, описание, цена, количество.
- Класс `Category` с атрибутами: название, описание, список продуктов.
- Атрибуты класса `Category`: `category_count` (количество категорий), `product_count` (общее количество товаров).
- Тесты для проверки инициализации и подсчета.

## Установка
1. Создайте виртуальное окружение: `python -m venv venv`
2. Активируйте: `source venv/bin/activate` (Linux/Mac) или `venv\Scripts\activate` (Windows)
3. Установите зависимости: `pip install -r requirements.txt`

## Магические методы

### `Product.__str__()`
Возвращает строку: `Название продукта, X руб. Остаток: X шт.`

### `Category.__str__()`
Возвращает строку: `Название категории, количество продуктов: X шт.`, где X — общее количество всех товаров в категории (сумма `quantity`).

### `Product.__add__(other)`
Позволяет складывать два продукта, возвращая общую стоимость всех товаров на складе:
`(цена_1 * количество_1) + (цена_2 * количество_2)`.

### Ограничения
- Сложение (`__add__`) работает только для объектов одного класса (проверка через `type()`).
- Метод `add_product` в `Category` принимает только объекты `Product` или его наследников (проверка через `isinstance`).
